# Дизайн

Ориентир — современные TUI вроде Claude Code CLI и opencode: спокойно, минималистично, один акцентный цвет, всё управляется с клавиатуры.

Свои макеты экранов рисуй в [`mockups/`](mockups/) по шаблону [`_TEMPLATE.md`](mockups/_TEMPLATE.md).

## Принципы
1. **Тишина по умолчанию.** Рамки и второстепенный текст приглушённые (серые). Яркое только то, что важно сейчас.
2. **Один акцент.** Акцентным цветом выделяются фокус, выбранная строка и курсор ввода. Остальные цвета только смысловые (добавлено, удалено, ошибка).
3. **Фокус виден по рамке.** У активной панели рамка акцентного цвета, у остальных — muted.
4. **Скруглённые углы** `╭╮╰╯` у всех рамок (`LineStyle.Rounded`).
5. **Подсказки всегда на экране.** Нижняя строка показывает клавиши для текущей панели.
6. **Прозрачность.** Перед любым действием можно увидеть git-команду, после — результат в Command Log.
7. **Обратная связь как в Claude CLI:** спиннер с глаголом во время работы, `✓` / `✗` по завершении.
8. **Работает в 80×24.** На узком экране панели складываются, ничего не обрезается без `…`.
9. **Фон терминала не трогаем** — используем фон пользователя, чтобы тема терминала оставалась его.

## Палитра (токены)

Все цвета в коде берутся только из `Theme`. Палитра основана на стандартной теме Neovim: блёклые синий и зелёный.

| Токен        | Цвет      | Где используется                                   |
|--------------|-----------|----------------------------------------------------|
| `fg`         | по умолч. | основной текст                                     |
| `muted`      | `#9B9EA4` | подсказки, второстепенный текст                    |
| `dim`        | `#4F5258` | версия, блики на волнах, рамки без фокуса          |
| `accent`     | `#A6DBFF` | рамка в фокусе, `❯`, курсор, кнопка в фокусе       |
| `green`      | `#B3F6C0` | второй цвет градиентов (логотип, волны)            |
| `selectionBg`| `#2C2E33` | фон выбранной строки                               |
| `success`    | `#B3F6C0` | `✓`, staged, `+` в diff, авторизованный пользователь |
| `error`      | `#FFC0B9` | `✗`, `-` в diff, ошибки                            |
| `warning`    | `#FCE094` | `⚠`, modified, «Не авторизован»                    |
| `info`       | `#8CF8F7` | ветки, `@@` в diff                                 |
| `backdrop`   | `#14161B` | предполагаемый фон терминала для приглушения цветов |

## Подсветка синтаксиса (diff)
C# подсвечивается через Roslyn (синтаксическое дерево, без компиляции). Цвета — тёмная тема Visual Studio:

| Токен | Цвет | Примеры |
|---|---|---|
| ключевое слово | `#569CD6` | `public`, `class`, `var`, `null` |
| управляющее слово | `#D8A0DF` | `if`, `return`, `foreach`, `try` |
| класс, record | `#4EC9B0` | `Console`, `List<T>` |
| struct | `#86C691` | `record struct Point` |
| интерфейс, enum, параметр типа | `#B8D7A3` | `IRunner`, `T` |
| метод | `#DCDCAA` | `WriteLine()` |
| параметр, локальная переменная | `#9CDCFE` | `args`, `total` |
| строка, символ | `#D69D85` | `"text"`, `'x'` |
| число | `#B5CEA8` | `42` |
| комментарий | `#57A64A` | `// …`, `/// <summary>` |
| препроцессор | `#9B9B9B` | `#if DEBUG` |
| остальное | `#DCDCDC` | |

Фон строк `+`/`-` (`AddedBg` / `RemovedBg`) сохраняется, подсветка меняет только цвет текста.

## Декорации
Анимации работают от общего таймера (`AnimatedView`, ≈12 кадров/с) и никогда не рисуются поверх элементов интерфейса.

- **Логотип** — вертикальный градиент `accent → green`.
- **Волны** — 5 нижних строк над подсказками. Цвет переливается между `accent` и `green`, приглушён к `backdrop`, гребень ярче глубины, над гребнями изредка блики `·`. Не рисуются, если окно ниже 26 строк.
- **Звёздное небо** — фон над волнами. Звёзды мерцают; у краёв экрана они ярче, крупнее (`• ⋆ ✧`) и примерно вдвое чаще, центр остаётся спокойным.
- **Падающие звёзды** — раз в 4–11 с появляются сбоку и летят от центра наружу, хвост `─ ·` гаснет.
- **Значок C#** — неподвижный, в левом верхнем углу стартового экрана. Шестиугольник 20×11 символов с вертикальными боковыми сторонами, три грани разной яркости (градиент `accent → green`), кольцо «C» и знак «#». Рисуется полублоками `▀▄`. Не рисуется в окне меньше 90×24.
- **Версия** `LGit vX.Y.Z` — цветом `dim` в правом нижнем углу.

## Плашки
- **Плашка** (`Segment.Badge`) — тёмная буква на цветном фоне. Показывает вид изменения файла, как в VS Code и Rider:

| Плашка | Значение | Цвет |
|---|---|---|
| ` M ` | изменён | `warning` |
| ` A ` | добавлен | `success` |
| ` D ` | удалён | `error` |
| ` R ` / ` C ` | переименован / скопирован | `info` |
| ` T ` | сменился тип файла | `warning` |
| ` U ` | новый файл (untracked) | `cyan` |
| ` ! ` | конфликт | `error` |

- **Мягкая плашка** (`Segment.Pill`) — цветной текст на приглушённом фоне того же цвета (`Theme.Tint`). Используется для заголовков разделов (` Staged `, ` Изменения `, ` Новые файлы `), ветки (` ⎇ main `), счётчика изменений и пользователя (` ● login `).

## Символы

| Символ | Значение                  | Символ | Значение            |
|--------|---------------------------|--------|---------------------|
| `❯`    | выбранная строка          | `✓`    | успех               |
| `●`    | авторизован               | `✗`    | ошибка              |
| `○`    | не авторизован            | `⚠`    | предупреждение      |
| `⎇`    | ветка                     | `↑2`   | впереди upstream    |
| `→`    | переименование `old → new` | `↓1`  | позади upstream     |
| `…`    | обрезанный текст          | `·`    | разделитель подсказок |
| `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` | кадры спиннера    |        |                     |

```
╭─ LazyGit ────────────────────────────────────────────────────────────────────╮

╰──────────────────────────────────────────────────────────────────────────────╯
╭─ [1] Файлы ────────────────╮╭─ Diff · Program.cs ────────────────────────────╮
│ Staged                     ││ @@ -1,8 +1,8 @@                                │

│ Изменения                  ││                                                │
│ ❯ ● Program.cs             ││   class Program                                │
│   ? .idea/                 ││   {                                            │
│                            ││       static void Main(string[] args)          │
│                            ││       {                                        │
╰────────────────────────────╯│ -         Console.WriteLine("Hello!");         │
╭─ [2] Ветки ────────────────╮│ +         Application.Run<MainWindow>();       │
│ ❯ ● main                   ││       }                                        │
│     feature/diff           ││   }                                            │
│                            ││                                                │
╰────────────────────────────╯│                                                │
╭─ [3] Коммиты ──────────────╮│                                                │
│   a1b2c3d init project     ││                                                │
│                            ││                                                │
╰────────────────────────────╯╰────────────────────────────────────────────────╯

```

- Левая колонка ≈ 35% ширины, правая — остальное.
- Номера `[1]`–`[3]` в заголовках = клавиши быстрого перехода.
- Правая панель показывает контекст выбранного: diff файла, лог ветки, изменения коммита.

## Диалог коммита
Похож на поле ввода Claude CLI: одна рамка, приглашение `>`, подсказки под ней.
Тип выбирается `tab` / `shift+tab`, выбранный выделен фоном `accent`. Если текст уже начинается с типа (`fix(ui): …`), он не дублируется.
Под полем — итоговый заголовок и счётчик (`dim` до 50, `warning` до 72, `error` больше 72), ниже — самая важная подсказка:
длина, английский язык, повелительное наклонение (`add`, а не `added`), строчная буква после типа, точка в конце.

```
╭─ Коммит ─────────────────────────────────────────────────────────────╮
│  feat   fix   docs   refactor   test   chore   style   без типа      │
│                                                                      │
│ > Added image.                                                       │
│                                                                      │
│ feat: Added image.                                             18/72 │
│ ⚠ Пиши как команду (add, fix), а не «added»                          │
│                                                                      │
│ Staged: 1 файл                                                       │
╰──────────────────────────────────────────────────────────────────────╯
 enter коммит · tab тип · esc отмена
```

## Подтверждение опасного действия
Рамка цвета `warning`, обязательно показываем точную команду. Фокус по умолчанию на «Отмена».

```
╭─ ⚠ Опасное действие ─────────────────────────────────────╮
│ Сбросить все изменения в Program.cs?                     │
│                                                          │
│ Будет выполнено:                                         │
│   git restore -- Program.cs                              │
│                                                          │
│ Это нельзя отменить.                                     │
│                                                          │
│        [ Отмена ]      [ Сбросить ]                      │
╰──────────────────────────────────────────────────────────╯
```

## Статус операций (строка над подсказками)

```
 ⠹ Отправка в origin/main…  esc отмена
 ✓ Отправлено 2 коммита в origin/main
 ✗ Push отклонён: на сервере есть новые коммиты. Нажми p, чтобы сделать pull
```

Сообщение `✓` исчезает через ~3 секунды, `✗` висит до следующего действия.

## Палитра команд (`ctrl+p` или `:`)
Как в opencode: поиск по всем командам с клавишами справа.

```
╭─ Команды ─────────────────────────────────────╮
│ > pus█                                        │
│ ❯ Push                                     P  │
│   Push с force-with-lease                ⚠ F  │
│   Push новой ветки (-u)                       │
╰───────────────────────────────────────────────╯
```

## Клавиши (глобальные)

| Клавиша       | Действие                    |
|---------------|-----------------------------|
| `1` `2` `3`   | перейти к панели            |
| `tab` / `shift+tab` | следующая / предыдущая панель |
| `↑↓` / `j k`  | навигация                   |
| `enter`       | открыть / зайти внутрь      |
| `esc`         | назад / отменить операцию   |
| `ctrl+p`, `:` | палитра команд              |
| `?`           | все клавиши                 |
| `~`           | Command Log                 |
| `r`           | обновить                    |
| `q`           | выход                       |

Клавиши панелей описаны в [PLAN.md](PLAN.md) и определяются командами (`IAppCommand.Key`).
