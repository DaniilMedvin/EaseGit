# Стартовый экран и вход

## Зачем этот экран
Выбрать репозиторий и при первом запуске предложить вход в GitHub.

## Когда открывается
При запуске `LazyGit [путь]`. Путь в поле: аргумент → последний открытый репозиторий → текущая папка.

## Клавиши

| Клавиша  | Действие                                   | Команда                       |
|----------|--------------------------------------------|-------------------------------|
| `enter`  | открыть репозиторий                        | `git rev-parse --show-toplevel` |
| `ctrl+o` | выбрать папку (zenity, без GUI — встроенный диалог) | —                    |
| `ctrl+g` | войти в GitHub (только если не авторизован) | `gh auth login --web`        |
| `esc`    | выход                                      | —                             |

## Состояния
- **Авторизован:** справа сверху `● логин` (зелёный), подсказки `ctrl+g` нет, окна входа нет.
- **Не авторизован:** `○ Не авторизован` (жёлтый).
- **gh не установлен:** в окне входа кнопка «Войти» недоступна, текст с командой установки.
- **Ошибка пути:** красная строка под полем.
