## Этап 11. Ежедневная работа с git
- [x] Разрешение конфликтов по фрагментам: `enter` на конфликтном файле — каждый блок `<<<<<<< / >>>>>>>`,

## Риски
- Вывод git зависит от версии и языка: только `--porcelain`, `--format`, `-z`, `LC_ALL=C`
- Пути с пробелами и кириллицей: `-z` и `core.quotepath=false`
- Долгие операции: только async, UI обновлять через главный цикл
- Авторизация: не перехватываем пароль, полагаемся на SSH / credential helper
