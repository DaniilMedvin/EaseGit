# Конфиг

Файл `~/.config/easegit/config.json` (или `$XDG_CONFIG_HOME/easegit/config.json`). Создаётся приложением,
можно править руками: имена ключей без учёта регистра, допускаются комментарии `//` и запятая после последнего элемента.
Если файл не разобрать, приложение запускается с настройками по умолчанию, а ваш файл копируется в `config.json.bad`.
Раньше программа называлась LGit и хранила конфиг в `~/.config/lazygit-cs/`: при первом запуске EaseGit он копируется
в новую папку сам (старый файл остаётся).

```jsonc
{
  "language": "en",                       // ru или en; не задан — по языку системы (LANG)
  "theme": "ocean",                       // dark (по умолчанию), light или имя своей темы
  "autoFetchMinutes": 5,                  // фоновый fetch раз в N минут; 0 — выключен
  "customThemes": {
    "ocean": {
      "base": "dark",                     // основа: dark или light
      "accent": "#00AAFF",                // любые цвета из списка ниже, только вида #RRGGBB
      "selectionBg": "#102030"
    }
  },
  "keys": {                               // id команды -> клавиша
    "files.stage": "s",
    "commit": "ctrl+k",
    "sync.fetch": "F5"
  }
}
```

## Темы
Переключение на лету: `T` — следующая тема по кругу (dark → light → свои по алфавиту), выбор запоминается.
Светлая тема рассчитана на светлый терминал: основной цвет текста берётся из самого терминала.

Цвета для `customThemes`: `muted`, `dim`, `accent`, `green`, `cyan`, `selectionBg`, `error`, `warning`, `addedBg`,
`removedBg`, `backdrop` (фон терминала: от него считаются плашки), а также подсветка кода `syntaxPlain`, `syntaxKeyword`,
`syntaxControlKeyword`, `syntaxClass`, `syntaxStruct`, `syntaxInterface`, `syntaxMethod`, `syntaxVariable`, `syntaxString`,
`syntaxNumber`, `syntaxComment`, `syntaxPreprocessor`, `syntaxDisabled`, `syntaxPunctuation`.
Опечатка в имени или цвете не ломает запуск: цвет пропускается, внизу показывается предупреждение.

## Клавиши
Переназначаются команды из справки (`?`), id видны в палитре команд и в [CommandRegistry](../EaseGit/UI/MainWindow.cs).
Запись клавиши: `s`, `S` (= shift+s), `ctrl+x`, `alt+f`, `F5`, `space`, `enter`, `esc`, `tab`, `up`, `down`, `left`,
`right`, `home`, `end`, `pageup`, `pagedown`, `delete`, `backspace`, цифры и символы (`?`, `~`, `,`).
Подсказки внизу и справка показывают новые клавиши. Если клавиша уже занята другой командой этого же экрана,
внизу появится предупреждение; навигация (стрелки, `j`/`k`) и клавиши внутри диалогов не переназначаются.

## Свои команды
Клавиша → команда shell. Запускается через `sh -c` (на Windows — `cmd /c`) в корне репозитория, stdin пустой.

```jsonc
"customCommands": [
  { "key": "ctrl+r", "title": "Открыть в Rider", "command": "rider {file}", "scope": "files" },
  { "key": "F6", "title": "Тесты проекта", "command": "dotnet test", "output": true },
  { "key": "ctrl+b", "title": "Ветка в браузере", "command": "gh browse --branch {current}", "confirm": true }
]
```

| Поле | Значение |
|---|---|
| `key` | клавиша, как в разделе `keys`; обязательно |
| `command` | команда; обязательно. Подстановки ниже берутся в кавычки shell — пробелы и кириллица в путях не ломают её |
| `title` | название в палитре (`ctrl+p`), справке и подсказке внизу; без него — сама команда |
| `scope` | где работает: `global` (по умолчанию), `files`, `commits`, `branches`, `stash` |
| `output` | `true` — окно с выводом по мере выполнения (`esc` останавливает); иначе в фоне, итог в строке статуса (ошибка — с последней строкой вывода) |
| `confirm` | `true` — перед запуском подтверждение с командой после подстановок |

Подстановки: `{file}` — полный путь выбранного файла, `{dir}` — его папка (или выбранная папка), `{commit}` — хеш
выбранного коммита, `{branch}` — выбранная ветка, `{current}` — текущая ветка, `{repo}` — корень репозитория. Другие
фигурные скобки (`${HOME}`) не трогаются. Нет значения (не выбран файл) — команда не запускается, строка статуса
подскажет, что выбрать. Клавиша, занятая встроенной командой того же экрана или глобальной, — предупреждение при
запуске, команда не добавляется. После команды экран обновляется: она могла изменить файлы.

## Остальное
| Ключ | Значение |
|---|---|
| `language` | `ru` или `en`; без ключа — по языку системы. `L` переключает и запоминает |
| `mascot` | `None`, `Claude`, `ChatGpt`, `Gemini` — маскот в углу diff (также `,`) |
| `showCommandLog` | панель Command Log открыта (`~`) |
| `autoFetchMinutes` | фоновый `git fetch --all --prune` раз в столько минут; без ключа — 5, `0` — выключен. Тихий: ничего не спрашивает (ssh с `BatchMode`), не пишется в журнал команд, без сети молчит; появились новые коммиты в upstream — `↓ На сервере 2 новых коммита: p — забрать` |
| `authPromptSkipped` | окно входа в GitHub пропущено |
| `lastRepoPath` | последний открытый репозиторий |
| `recentRepos` | недавние репозитории (до 20): в них окно GitHub ищет локальную копию проекта PR |
