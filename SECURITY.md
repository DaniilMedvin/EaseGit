# Security

If you find a vulnerability, please report it privately via
[GitHub Security Advisories](https://github.com/DaniilMedvin/LazyGit/security/advisories/new),
not in a public issue. You will get an answer as soon as possible.

Нашли уязвимость — сообщите приватно через ссылку выше, а не в открытом issue.
